# 原 HTML 与 Unity 组件对照

| HTML 功能 | Unity 实现 |
| --- | --- |
| Phaser Scene / 状态切换 | WuxiaGame 与 GamePhase；主场景 WuxiaMain |
| Arcade 地面物理 | Rigidbody2D / BoxCollider2D；以固定 60Hz 手动模拟 |
| 角色帧切片与挂点 | ArtFrames.json、ArtLibrary、SpriteRenderer；PNG 与透明切片保持 |
| 原角色 / 敌人 / 首领 | Resources/Prefabs 的五类原生物理预制体，C# 驱动动画 |
| 原关卡数据 | Room0 至 Room4 的 ScriptableObject；Content 汇总 |
| 近战与远程 | 原生命中判定、往返飞剑、可穿高台的敌方飞刃 |
| Boss 行为 | 原生状态机、魔主随机选择、地波、庇所与碎台 |
| 万剑归宗 | 十二跟踪飞剑、复用粒子 / 光线、外内法阵 PNG |
| 无尽 / 增益 | RogueState、Rules、原生 UGUI Button 与可逆卡面预览 |
| 原 UI | UGUI Canvas、Image、Text；中文字体内置 |
| Web Audio | AudioSource + 原原创器乐 wav；柔和刀剑与碎石 AudioClip |
| JavaScript 主循环 | C# FixedUpdate；特效、投射物和音效实例有数量上限 |

Unity 不加载 HTML，不启动网页服务器，也不依赖浏览器、npm 或外部网页服务。资产包含在项目和原生播放器内。

世界布局和战斗关键时间沿用当前 HTML 版本；渲染层与碰撞引擎不同，不承诺两个引擎的每一个像素与运动轨迹完全相同。第一版原生移植已完成主要流程，后续可根据实际试玩继续调整手感。

截图和自动化检查包括真实 Unity 物理模拟、Native UGUI 事件，以及本机 Metal 图形播放器的渲染。测试的选择事件由项目内自动化触发，不等同于长期人工试玩。
