# Unity 1.6 无尽扩展素材来源与修改记录

## 八卦召灵阵（实际使用）

- 阴阳纹作者：Delapouite，官方页面 https://game-icons.net/1x1/delapouite/yin-yang.html 。
- 许可：CC BY 3.0，https://creativecommons.org/licenses/by/3.0/ 。
- 原始SVG：yin-yang-original.svg，来自 https://game-icons.net/icons/ffffff/transparent/1x1/delapouite/yin-yang.svg 。
- 改编：将阴阳纹缩放、改为旧金色，组合本项目绘制的八卦爻纹、八角阵框及墨紫底晕。编辑源 summon-bagua.svg，运行时 summonBagua.png。派生美术保留CC BY 3.0署名。
- 开启表现：地面阴阳阵先展开，空中八卦阵与三张朱砂符浮现、墨烟流动、敌人从符阵淡入。时序与分批刷怪规则不变。
- 灵雾沿用CodeManu的CC0 Free Pixel Effects Pack中已导入的24帧pixelMist；原始包及署名位于 ../Unity1.3/ 。朱砂符沿用游戏wuxiaAtlas原画，来源见历史HTML记录。

## 白骨剑卒与魔瞳

- 作者：LuizMelo。
- 官方发布页：https://luizmelo.itch.io/monsters-creatures-fantasy
- 作者在该页面明确提供 CC0 许可，允许免费商业及非商业用途，署名可选。
- 原始包：Monsters_Creatures_Fantasy.zip，另保存官方1.2及1.3增补包作为下载记录。
- 本版实际使用 Skeleton 的 Idle / Walk / Attack 与 Flying eye 的 Flight / Attack。
- 五张运行时 PNG 从原 ZIP 原样复制；ArtFrames.json 仅记录透明边界裁切、脚底/中心锚点。
- 未将 Goblin、Mushroom 或增补包动画加入实际刷怪。魔道符师使用原游戏 masterAtlas 缩小形象，来源沿用历史说明。
