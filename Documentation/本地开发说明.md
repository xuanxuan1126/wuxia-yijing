# 武侠遗境 · Unity 1.4

由本地 HTML 游戏 0.11.10 迁移而来，使用 Unity 6.3 LTS（已验证版本 6000.3.24f1）。角色、物理、战斗、音频和鼠标选卡均运行在 Unity / C# 中。

## 打开项目

1. 在 Unity Hub 中选择「添加现有项目」，选择本文件夹。
2. 使用 Unity 6000.3.24f1 打开，首次会自动导入素材。
3. 打开 `Assets/Wuxia/Scenes/WuxiaMain.unity`，点击编辑器上方 ▶ Play。
4. 菜单可进入剧情、石像试剑、魔主决战或无尽试炼。

## 直接离线游玩（不需要 Unity）

解压压缩包后，打开 `试玩程序`，选择自己系统的文件夹：

| 系统 | 启动入口 | 架构 |
| --- | --- | --- |
| Windows | `Windows/WuxiaYijing.exe` | 64 位 x86（Windows 10 21H1+ / 11） |
| macOS | `macOS/武侠遗境.app` | macOS 12+ 通用版，Apple Silicon / Intel |
| Linux | `Linux/开始游戏.sh` 或 `Linux/WuxiaYijing.x86_64` | 64 位 x86（Ubuntu 22.04 / 24.04） |

运行时引擎、Mono、图片、中文字体、音乐和关卡均包含在包内；无需安装 Unity、Node、Python或联网。请先完整解压，保留每个系统文件夹里的所有文件，不要单独移动 exe 或 Data 文件夹。Mac 首次运行若被系统拦截，请在系统设置的「隐私与安全性」中允许打开此应用。Linux 若解压软件丢失可执行权限，可在文件属性中勾选允许执行。

要继续编辑游戏，才需要 Unity 编辑器及对应平台构建模块。

## 操作

| 按键 | 操作 |
| --- | --- |
| A / D、左右方向键 | 移动 |
| 空格 | 跳跃；长按越过石像 |
| J | 挥剑 |
| K | 飞剑往返，约 5 秒冷却 |
| Shift | 踏云御剑，短暂无敌 |
| L | 万剑归宗，十二飞剑追敌 |
| E | 进入山门、参悟剑诀、开启封印 |
| Esc | 暂停 / 继续 |
| H | 一键返回主界面 |
| M | 静音 |

剧情在藏剑石窟习得踏云诀与万剑归宗；试剑、决战与无尽模式默认掌握。

## 已迁移内容

- 青竹山径、悬桥古道、藏剑石窟、镇岳山门、归元禁庭；三幅序章与归元结局。
- 白衣双腿交替八帧跑步，保留黑衣整身动作；近战、飞剑、御剑冲刺与背后法阵。
- 山匪跃击、纸鹤锁定瞄准与赤焰飞刃。
- 石像震地、冲撞碎台后停止与硬直；魔主随机三招、追魂符、三叠震荡与魔潮草庇所。
- 无尽成长：每五波石像、每十波魔主，十二类增益。清波 4.5 秒仍可移动，卡面可改选后确认；首领获得两次选择。
- 太极气血、明显的技能冷却、不同首领血条、中文卷轴界面、安静器乐和柔和音效。

## 后续编辑

- `Assets/Wuxia/Resources/Data/GameSettings.asset`：移动、跳跃、冲刺、冷却、音量。
- `Assets/Wuxia/Resources/Data/Room0.asset` 至 `Room4.asset`：Inspector 编辑各关高台、敌人、山门坐标。
- `Assets/Wuxia/Resources/Data/Content.asset`：剧情关卡顺序及增益名称、说明与等级上限。
- `Assets/Wuxia/Resources/Prefabs`：五类角色的 Rigidbody2D / BoxCollider2D 预制体。
- `Assets/Wuxia/Resources/Art`：已转换为 Unity 可用 PNG 的素材；原画风保持。
- `Assets/Wuxia/Resources/Data/ArtFrames.json`：图集裁切、人物脚底与手臂遮挡的挂点。
- `Assets/Wuxia/Scripts`：C# 游戏、敌人状态机、投射物、特效池、原生 UGUI 与音频。

场景包含游戏控制器，进入 Play 后按配置生成当前关卡及界面。世界坐标 1 Unity 单位 = 100 原游戏像素；关卡资产使用原图左上角坐标系（Y 向下），由 PixelWorld 转换。

菜单「武侠遗境」提供打开主场景、回归检查及 macOS / Windows / Linux 构建。重建项目场景与预制体会重置场景/预制体，仅在需要恢复默认入口时使用；不会重置现有关卡与参数资产。

## 验证与移植说明

`Documentation/Validation` 存放 Unity 回归结果与原生播放器截图。自动检查涵盖移动跳跃、山匪伤害、平台破碎、护心草、30 波奖励流程、可逆选卡、回春丹、所有增益及资源清理。程序截图由真实 Unity 播放器输出。

本版保留已认可的整身角色动画与核心玩法，修正了固定帧绘制、台沿摩擦/错误落地、飞剑反复换目标与高速漏判。按显示帧插值移动图层，60 Hz 物理独立运行。普通与强化震地恢复 HTML 的破土尖石。

魔潮：三秒蓄力，顶端浅纸提示显示进度及倒计时；两株归元草形成明确的玉色庇所边界。爆发时两面紫色波墙由魔主向两侧扫过，波前经过才判定，庇所内可抵御；跳跃、普通御剑无敌不能代替进入庇所。该招每次最多对玩家造成一次伤害。

新增 CC0 金属剑、六帧飞剑剑光、深木浅铜玉扣高台；卷轴改为浅纸墨字，卡面与按钮有不同边框。详细来源、原始下载包与改编说明在 `Documentation/Attribution/Unity优化版/来源与修改说明.md`。

Unity 与 Phaser 的物理手感仍会有差异；本机验证的是 macOS 构建。原 HTML 工程与桌面旧 Unity 项目保留。

`Tools` 保存本次导入脚本。游戏运行和继续制作无需 Node、Python、原 HTML 文件夹或联网；只有重新从 HTML 源素材导入时才需要这些可选工具。

## 1.2 外观与界面更新

主角佩剑、御剑、往返飞剑、万剑归宗与护体剑统一回退至原 blade 素材和上一版尺寸；1.1 的索敌、命中、插值、地震/魔潮修正保留。已学天赋为左侧 22 像素图标，三列紧凑排列，等级提升后显示小数字。选卡页采用深色图标底座、明确的已选标记及浅色底部确认栏，深青确认按钮便于辨认。

应用图标位于 `Assets/Wuxia/AppIcon/wuxia-app-icon.png`，制作来源与最终提示词见 `Documentation/Attribution/应用图标制作说明.md`；已设置 Unity 默认与桌面平台应用图标，构建 macOS 程序时自动写入。


## 1.3 动作、剑柄与命中更新

白衣跑步重新绘制八帧，左右腿交替承重、抬膝和蹬离；双腿裤料与靴子颜色统一，仅保留自然阴影。步频按地面位移计算，正常速度约 0.8 秒一周期。

腰剑沿用原 blade.png，游戏内宽度从 5 提升至 10 像素，长度仍为 78；身体、剑、近侧袖臂分别绘制。袖臂按轮廓提取原图像素，避免整块躯干遮掉剑柄。冲刺继续御剑。

石像原画面朝左，修正对应的左右镜像，冲撞锁定方向并清除反向残速；玩家绕到背后不会让石像中途倒冲。近战弧光现在跟随角色物理位置，左向攻击正确水平镜像；飞剑命中特效落在扫掠碰撞的接触点。

命中采用 CC0 六帧金属亮核、碎光和消散，寒冰采用 CC0 霜晶动画并跟随被冻结敌人。去掉原先缩成单色方点的 Burst。素材与许可见 Documentation/Attribution/Unity1.3/素材来源.md，生成跑步图集与最终提示词见同目录的跑步素材制作说明.md。

验证：359 项基础 + 26 项物理/追踪/界面 + 18 项本版动作/冲撞/命中，共 403 项自动回归；实际 macOS Unity 程序的画面与鼠标测试见 Documentation/Validation/NativePlayer13。


## 1.4 高台碰撞、佩剑遮挡与跨平台发布

剧情高台的地形碰撞现在覆盖完整可见身高：主角 90 像素、山匪 84 像素，碰撞盒向上扩展，脚底位置不变。适当抬高过低高台，并拉开重叠上下台间距，确保站立通行的头顶净空。保留原来的攻击范围、伤害判定、跃起高度和高台实体碰撞；在高台底部跃起时头部不再先穿进去。

原剑款保持不变。剑身位于衣袍后方，护手与剑柄位于身体和近侧袖臂之间；所有图层使用同一帧姿势、同一物理移动插值。腰剑、御剑的挂点在切换姿势时立即切换，避免跨姿势插值把剑从腰部拖过衣服。挥砍和飞剑出手时隐藏腰间两段剑，防止重复显示。

新增台底碰撞与低台通行、两面佩剑、御剑切换与落台检查，共 44 项，与既有 403 项一同完成回归检查，总计 447 项。macOS 真实播放器还覆盖剧情台底跃起及御剑前后的画面；记录在 `Documentation/Validation/NativePlayer14`。Windows 与 Linux 是正式原生构建，已检查构建结果和运行库完整性；本机为 Mac，尚未在真实 Windows / Linux 电脑上试玩。

桌面完整项目包附带三个系统的程序。另有每个系统单独的玩家包，分享时可只发送对应系统的包；玩家包也包含素材许可说明。

运行系统要求依据 [Unity 6.3 官方播放器要求](https://docs.unity.com/en-us/engine/6000.3/manual/get-started/install-and-upgrade/getting-started-installing-unity/system-requirements#desktop)，不要求玩家安装编辑器。
