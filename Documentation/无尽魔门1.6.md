# 无尽魔门 1.6 设计与验收（历史版本）

当前版本请看 [群敌试炼1.7](群敌试炼1.7.md)：小批数、每批人数、生命和攻击持续增长，三个新敌人已替换为独立原画。本文保留1.6当时的规则和素材记录。

本版只扩展无尽玩法，保留1.5的白衣剑客、完整八帧跑步、腰剑图层、万剑归宗与纸质选卡。剧情关卡、五波石像 / 十波魔主、可破碎高台、清场4.5秒自由移动和首领两次机缘规则保留。

## 成长卡池

旧12卡保留，新增四张属性卡与四张自动剑诀，共20张。自动剑诀无需额外按键。

| 卡 | 上限 | 作用 |

| 追风步 | 5重 | 移速每重+6%，最高+30% |
| 凌霄步 | 4重 | 御剑冷却每重-12%，最高-48% |
| 护体罡气 | 4重 | 非坠落伤害每重-8%，最高-32% |
| 剑心澄明 | 4重 | 会心率每重+8%，会心造成165%伤害 |

剑诀伤害同时乘淬锋诀，并能触发会心；三种定时剑诀冷却同时乘流光御剑。没有射程内目标时不消耗完整周期。卡面预览使用独立成长状态，改选不会扣血、加属性或提前学习；确认才生效。

## 敌人种类

- 原黑衣山匪与御剑纸鹤继续出现。
- 第6波：魔道符师，保持中距离，蓄势释放单张紫色追魂符。形象沿用魔化门派造型缩小，区别184高首领与92高随从。
- 第8波：白骨剑卒，CC0盾剑像素动画。靠近后锁定挥剑方向、0.36秒出刀，具有前摇与收招。
- 第12波：魔瞳，CC0八帧飞行/攻击动画。使用完整碰撞体检查俯冲路线，被高台阻挡时先绕行；0.65秒瞄准预告后按距离俯冲，锁定预告位置，玩家可跳跃或御剑避开。
- 新敌人入场有0.45秒淡入保护，不在出现的一瞬间造成接触伤害。退避受地图边界约束，避免跑出地图造成清波卡住。

## 魔门分批

普通波次：1～3波直接少量出现；4～8波两批；9～18波三批；19波起四批。普通波次总数量为 min(26, 3 + floor((wave-1)*0.65) + 2*(batches-1))，最多同时14只存活小怪。

每批至多两个魔门，优先选离主角远、地面无高台的四个候选位置。魔门先从地面展开，1.3秒后出场；存活怪太多会等待位置，传送门维持开启。基础批间隔10.5秒，当前存活不超过2只时可提前到4.5秒后；还有伏兵时不会误触发奖励。

第15波起首领带3～6只延后出现的随从，最多一小批，基础延后8秒。随从也要清完才能双重领奖。原生命、攻击随波次增长公式保留。
